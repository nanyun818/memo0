# 先学开源评测，再用于 Agent Desk

更新：2026-10-31。学习者要求先学习所贴清单中的七个评测项目；既有 Agent Desk 继续作为最终评测对象。此前按功能逐节读源码的顺序暂停，遇到需要评测的功能时再读对应实现。每天约5小时，暂沿用原两周终点11月8日，共9个学习日约45小时。

状态：路线与今日离线预览已准备；DeepEval、Langfuse、Ragas、Inspect AI、lm-evaluation-harness、AgentHorizon 尚未在本课程中完成真实实验。排期是目标，不是完成记录。两周目标是形成一套可解释、可复跑的应用评测闭环；七个框架的生产部署与深入掌握超出这个时间范围。

## 七个项目怎样分工

| 学习顺序 | 项目 | 要回答的问题 | 本轮实际交付目标 |
|---|---|---|---|
| 1 | promptfoo | 同一组题，改 Prompt 后哪些答案变好或变坏？规则有没有漏判？ | 沿用已有5题真实对照，完成六条固定答案的模型裁判实验和分歧记录 |
| 2 | DeepEval | 怎样用 Python 将质量要求写成可重复测试？怎样区分结果、过程与单步？ | 复用同批语义样例；实现一个语义指标，再做工具名与参数错误的隔离样例 |
| 3 | Langfuse | 一次请求经历了什么？失败例怎样进入数据集与下一次实验？ | 一条脱敏 trace、一个数据集、一次版本对照；记录耗时、用量及评分 |
| 4 | Ragas | 是没有检索到依据，还是有依据却回答错了？ | 对同一批问答分开记录检索召回、资料噪声与回答依据一致性 |
| 5 | Inspect AI | 一个完整评测任务怎样组织数据、执行、工具、评分与日志？ | 一个只读小任务，保存 task 定义、评分器和日志；不先搭复杂环境 |
| 6 | lm-evaluation-harness | 标准模型 benchmark 的任务和分数如何产生？ | 阅读一个任务定义与评分过程；选择接口兼容的少量样本试跑，或如实记录阻塞 |
| 7 | AgentHorizon | 裁判能否从很长的截图/动作记录中判断任务是否成功？ | 阅读协议、一个可获得的轨迹样例和判分理由；具备合适多模态裁判后再试跑 |

这些工具能力有重叠，并非必须串联部署。DeepEval也能记录执行过程，Langfuse也提供评测，Ragas也不只评RAG。本课程按上表选取学习重点。

## 对所贴资料的校正

1. AgentHorizon主要是评估“判断 computer-use Agent 成功与否的裁判”，不是给普通桌面应用自动安装一个操作Agent。官方仓库提供评测程序、提示与裁判实现，轨迹数据另行分发。只读文本不能替代需要截图的多模态实验。
2. Agent Desk 是桌面工作台；现有普通聊天、知识检索、手动MCP和任务执行属于不同路径。不能把手动调用记录包装成模型自主选择工具的证据。先用清楚标注的合成轨迹学习，再采集真实任务引擎记录。
3. Agent Desk 已有 FTS5/BM25 知识检索，所以Ragas可以提前；没有向量库也可以讨论和评测RAG。Mem0、OpenViking是待比较的记忆/上下文方案，不是评测框架，暂放在评测基线之后。
4. lm-evaluation-harness 与 Google Harness² 是不同项目。聊天API能生成文本，不意味着能运行所有依赖loglikelihood的任务。选任务前核对模型后端支持的请求类型；小样本不是论文可比成绩。
5. Langfuse同时支持观测、数据集、实验和评分，不只“存日志”。不在尚未检查资源的既有服务器上直接部署整套平台；到该节再核对资源，选择可运行方案。
6. DeepEval当前文档有多种评测模式。教程执行前固定包版本、核对所需输入、显式配置裁判服务；不能假设所有指标仅有一个免费本地函数，或只凭最终文本就能测完整过程。

## 同一批案例贯穿工具，而不是每装一个工具就换一套题

先复用现有六条合成答案做评分器校准。之后逐步增加Agent Desk场景：资料足够、资料不足、改写问题、跨项目资料隔离、撤销授权、工具参数错误、取消或超时。代码可自动验证的行为优先用确定规则；语义问题再用明确标准的模型评分并人工复核。

应用质量、裁判质量分开报告：

- 应用质量：真实应用输出有多少满足预先约定的要求。
- 裁判一致性：裁判的判分与经复核参考标签有多少一致。当前标签来自AI助教建议，尚不能叫专家标注。
- 执行错误：没有得到有效输出或有效判分，单列，不混成内容不合格。
- 开发集与保留集分开；用来改Prompt的题不能同时证明对新问题有效。先保存版本、题目和标准再运行。

每个知识块留下：中文概念解释、配置/版本、可公开样例、复跑命令、实际结果、至少一个失败分析、AI协助范围、学习者独立修改。没有跑出来的结果只记“已准备”。不发布生产对话、数据库或凭据。
