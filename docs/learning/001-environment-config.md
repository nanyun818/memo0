## 核心概念

- Windows PowerShell 的本地提示符与 SSH 登录后的 Linux 提示符属于不同执行环境。连接断开后，命令会在本地执行。
- 虚拟环境隔离 Python 依赖，不创建新服务器。
- app.py 执行逻辑；config.json 提供名称、top_k、关键词和知识。
- 当前检索按命中的关键词数量排序，同分时保持配置顺序；top_k 表示最多返回的匹配条数。
- JSON 的相邻字段或数组条目用逗号分隔，最后一项后不加逗号。
- Git commit 保存本地版本；发布到 GitHub 还需要实际同步并核验。

## 可重复操作

先进入本仓库并激活虚拟环境：

```bash
source .venv/bin/activate
which python
python -m json.tool config.json
python app.py '记忆'
python app.py '今天会下雨吗？'
git status --short
git diff -- config.json
```

## 代码入口

app.py 中 load_config 读取与校验，lookup 检索与排序，main 解析参数、组织结果并记录日志。日志默认保存在本地 logs 目录，已被忽略。
